# EatWell – Diet and Nutrition Management App

## Overview

EatWell is an Android-based diet and nutrition management application developed to help users achieve their health and fitness goals through personalized diet planning and nutrition tracking.

The application provides customized recommendations for weight loss, weight gain, and weight maintenance while helping users monitor their daily nutritional intake.

---

## Features

* User Registration and Login
* Firebase Authentication
* Personalized Diet Recommendations
* Weight Loss Planning
* Weight Gain Planning
* Weight Maintenance Planning
* BMI Calculation
* Daily Nutrition Tracking
* Meal Planning
* Activity Tracking
* Notes and Journal Management
* Nutrition History and Records
* Firebase Realtime Database Integration

## Installation

### Clone Repository

```bash
git clone https://github.com/sanika0517/EatWell.git
```

### Open in Android Studio

1. Launch Android Studio
2. Select Open Project
3. Choose the EatWell project folder

### Configure Firebase

1. Create a Firebase project
2. Add Android application
3. Download `google-services.json`
4. Place the file inside:

```text
app/google-services.json
```

### Build and Run

```bash
Sync Gradle
Run Application
```
